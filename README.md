# 圖誌

LLM 文字互動冒險。地圖上的座標是真的：人用圓點標位置，距離決定誰聽得見你說話。每到新場所，會先生成俯視圖，再用視覺模型把家具與出口讀成文字，讓主持人和地圖對得上。

試玩不必先接 API：標題畫面選「試玩樣本」，可直接走進雨夜的〈北風亭〉。

## 需要什麼

- Node.js 20 以上
- 一套 [OpenAI Compatible](https://platform.openai.com/docs/api-reference) 的文字／視覺／地圖繪圖／角色繪圖端點（可四份分開設定）
  - 預設走 xAI Grok（平台金鑰或自備金鑰）
  - 也可改 OpenAI、OpenRouter 或其他相容服務

樣本場景不呼叫模型也能開；自訂主題、新地圖、人物立繪才需要 API。

## 啟動

```bash
npm install
npm run dev
```

瀏覽器打開 [http://localhost:8080](http://localhost:8080)。

| 指令 | 用途 |
| --- | --- |
| `npm run dev` | 開發伺服器（`0.0.0.0:8080`） |
| `npm run build` | 正式建置 |
| `npm run preview` | 預覽建置結果 |
| `npm run typecheck` | TypeScript 檢查 |

平台模式會讀環境變數 `XAI_API_KEY`。沒有平台金鑰時，到「設定 API」改成自備端點與金鑰。

### Docker

```bash
docker compose up --build
```

或：

```bash
docker build -t llm-map-rpg .
docker run --rm -p 8080:8080 -e XAI_API_KEY=xai-你的金鑰 llm-map-rpg
```

開發用（原始碼掛進容器、熱重載）：

```bash
docker compose --profile dev up --build
```

映像內建置走 Nitro `node-server`，對外聽 `8080`。金鑰用環境變數傳入即可，不要寫進映像。樣本場景不需要金鑰。

## 怎麼玩

1. **設定 API**（可選）：文字、視覺、地圖繪圖、角色繪圖各一份連線。視覺負責讀地圖，地圖繪圖負責俯視圖，角色繪圖負責全身立繪。
2. **開始新遊戲**：填主題、地圖／角色圖風格、角色提示，生成 lorebook、初始場景與玩家。
3. **或試玩樣本**：北風亭已畫好地圖、標好物件。
4. 點地圖會先跳出行動選單，不會因誤點就推進回合。
5. 選單左側是人物全身圖；右側是「走過去／交談／坐下」等選項，也可自己寫意圖。

存檔在瀏覽器 IndexedDB，可從「讀檔」繼續，也可匯出備份。

### 距離

座標是地圖百分比（左上 0,0）。

| 距離 | 含義 |
| --- | --- |
| ≤ 12 | 伸手可及：低語、碰觸 |
| ≤ 24 | 近處可談 |
| ≤ 36 | 同區須揚聲，細節不清 |
| > 36 | 聽不見；遠處只見人影 |

遠在地圖另一端的人，不能當成面對面聊天。

### 立繪

- 第一次見面須在中距離以內點擊，才會依外觀生成全身圖（正面、無場景背景）。
- 隔太遠還沒見過面：只顯示無臉黑影。
- 見過面再遠看：立繪轉暗，表示看不清楚。
- 地圖風格與角色圖風格分開設定，可在編輯模式「風格」分頁改。舊存檔只有一條風格時兩邊都會沿用。

### 編輯模式

遊玩畫面標題列、眼睛圖示左邊的鉛筆：

- 拖曳物件框與人物圓點
- 拉物件右下角縮放
- 改名稱、種類、外觀、背景；外觀與背景會成為下一回敘事的當前真相
- 新增／刪除物件與人物
- 編輯時不會推進回合

## 技術

TanStack Start + React + Tailwind v4。AI 呼叫走伺服器函式（chat completions、vision、images/generations）。遊戲狀態存在瀏覽器，不需帳號。
